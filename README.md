### SATUSEHAT FHIR SDK

**Go · HL7 FHIR · REST API · OAuth 2.0**

A type-safe Go SDK that abstracts SATUSEHAT's FHIR REST APIs into a reusable developer library.

- Strongly typed FHIR models
- OAuth 2.0 Client Credentials authentication
- Automatic token refresh and caching
- Modular FHIR service architecture
- Based on SATUSEHAT's Postman API collection and FHIR specifications
